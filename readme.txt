Child theme of Hello Elementor for megavoters.com.

== Description ==

Starter child theme for the Oligopoly / United Citizens discovery portal.

This theme is for megavoters.com only. Do not copy Legacy to Live By (LLB)
templates or Human Gold Rush logic into this folder.

- Theme: landing pages, branding, booklet download links (Phase 1–2)
- Plugin (later): devices, RSVPs, encounters, consents (Phase 4)

== Installation ==

1. Keep the parent theme `hello-elementor` installed.
2. In WP Admin go to Appearance → Themes.
3. Activate **MEGAvoters**.
